# Ecos de Aurora

RPG de aventura 2D em Python e Tkinter, com exploração livre, três santuários, combate de espada, níveis, tesouros e chefe final.

## Como jogar

Requer Python 3.10 ou superior, Tkinter e ambiente gráfico. Não requer pacotes pip.

Na raiz deste repositório:

```bash
python3 jogos/ecos-de-aurora/ecos_de_aurora.py
```

No Windows, abra `Abrir_no_Windows.bat` na pasta do jogo, com Python instalado.

## Controles

| Tecla | Ação |
|---|---|
| WASD / setas | Mover |
| Espaço | Espada |
| E | Interagir |
| Q | Poção |
| Shift | Esquiva |
| M | Mapa |
| Esc | Pausa |
| F5 / F9 | Salvar / carregar |

Derrote os sentinelas de cada santuário, interaja com os três cristais e enfrente o Guardião do Eclipse nas ruínas do sudeste. A fogueira restaura vida e salva o progresso.

O progresso fica em `.ecos_de_aurora_save.json` na pasta pessoal do jogador.
